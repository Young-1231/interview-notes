## 导读
操作系统八股以概念对比为主：进程和线程、进程状态转换、死锁四条件与预防、虚拟内存、分页和分段、用户态和内核态、零拷贝、调度算法。LRU 常和手撕题一起考。
- 先背：进程/线程区别、死锁四条件、虚拟内存解决的问题、LRU（哈希表 + 双向链表）。
- 最容易混的：死锁预防（破坏条件）和死锁避免（银行家算法）；分页的内部碎片和分段的外部碎片；软链接和硬链接。

## 补充: 什么是进程、线程？它们之间有什么区别
常见追问：线程共享进程的地址空间、堆、全局变量、打开的文件，但各自有独立的栈、寄存器和程序计数器。同一进程内的线程切换不用切换页表，所以 TLB 不必失效，开销小。
Linux 内核不严格区分进程和线程，两者都是 task_struct，创建时通过 clone() 的共享标志决定共享哪些资源。协程是用户态调度的，切换不进入内核。

## 补充: 什么是虚拟内存？它解决了什么问题
常追问的地址翻译过程：先查 TLB，未命中再查多级页表（x86-64 常见 4 级）。页表项无效时触发缺页异常，由内核分配物理页或从磁盘/swap 调入，然后重新执行该指令。
多级页表的作用是节省页表本身占用的内存，没有用到的地址区间不需要分配下级页表。

## 补充: 什么是零拷贝（Zero-Copy）技术
常追问具体实现。传统 read + write 有 4 次拷贝（2 次 DMA + 2 次 CPU）和 4 次上下文切换。mmap + write 省掉一次 CPU 拷贝。sendfile 只需 2 次上下文切换；网卡支持 SG-DMA 时（Linux 2.4+），CPU 拷贝次数降为 0。
Kafka 消费端用 sendfile（Java 的 FileChannel.transferTo），RocketMQ 用 mmap。

## 自测
### 进程和线程的根本区别？
进程是资源分配的基本单位，线程是 CPU 调度的基本单位。同一进程内的线程共享地址空间，但各自有独立的栈和寄存器。
### 进程的三种基本状态及转换？
就绪、运行、阻塞。就绪 → 运行靠调度；运行 → 就绪因为时间片用完或被抢占；运行 → 阻塞因为等待 I/O；阻塞 → 就绪因为事件完成。阻塞不能直接变成运行。
### 死锁的四个必要条件？
互斥、占有并等待、不可剥夺、循环等待。四个条件同时满足才会发生死锁。
### 死锁预防和死锁避免有什么区别？
预防是静态地破坏某个必要条件，比如一次性申请全部资源、按序申请资源。避免是在分配资源时动态判断，保证系统始终处于安全状态，代表是银行家算法。
### 虚拟内存解决了什么问题？
进程间内存隔离；程序可以使用比物理内存更大的地址空间；每个进程看到连续的地址空间，而物理页可以离散分配。
### 分页和分段的区别？
页大小固定，对用户透明，会产生内部碎片。段按逻辑划分，大小可变，便于共享和保护，会产生外部碎片。
### TLB 是什么？
页表项的硬件缓存，命中时不必查内存中的页表，直接完成地址翻译。
### 什么情况下会从用户态进入内核态？
三种：系统调用（主动请求）、异常（如缺页、除零）、外设中断。
### 为什么要区分用户态和内核态？
特权指令和关键资源只能在内核态访问，防止用户程序有意或无意破坏系统。
### 硬链接和软链接的区别？
硬链接是指向同一个 inode 的多个目录项，不能跨文件系统，也不能链接目录。软链接是一个单独的文件，内容是目标路径，可以跨文件系统；目标被删除后软链接失效。
### 零拷贝常见的实现有哪些？
mmap + write，以及 sendfile（配合 SG-DMA 可以做到 0 次 CPU 拷贝）。核心是减少 CPU 拷贝和上下文切换。
### LRU 怎么实现 O(1) 的 get 和 put？
哈希表负责 key 到链表节点的 O(1) 定位，双向链表维护访问顺序。访问时把节点移到表头，容量满时删除表尾节点。
### 常见的进程调度算法？
FCFS、SJF、优先级调度、时间片轮转（RR）、多级反馈队列。多级反馈队列兼顾响应时间和吞吐，SJF 可能让长作业饥饿。
### 大端和小端的区别？
大端是高位字节存在低地址，小端是低位字节存在低地址。x86 是小端，网络字节序是大端。
### 为什么需要内存对齐？
CPU 按字长或缓存行访问内存，对齐后一次就能读完数据。有些平台访问未对齐的地址会直接报错。
